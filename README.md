# 🏆 Forum Sport

## 📖 Description

Forum Sport est une plateforme web dédiée aux passionnés de sport. Elle permet aux utilisateurs de créer un compte, participer à des discussions et échanger autour de différentes disciplines sportives.

Le projet a été développé dans le cadre d'un travail de groupe afin de mettre en pratique le développement web full-stack avec une architecture client/serveur.

---

## ✨ Fonctionnalités

* Création et gestion de compte utilisateur
* Connexion et déconnexion sécurisées
* Création de publications
* Réponse et interaction avec les publications
* Catégorisation des discussions par sport
* Gestion des profils utilisateurs
* Interface intuitive et responsive

## 🚀 Installation

### Cloner le projet

```bash
git clone <url-du-repository>
cd projetForum
```

### Installer les dépendances

```bash
go mod tidy
```

### Lancer le serveur

```bash
go run main.go
```

Le site sera ensuite accessible depuis votre navigateur à l'adresse :

```text
http://localhost:8080
```
